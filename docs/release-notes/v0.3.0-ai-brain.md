# v0.3.0-ai-brain — Phase 3: SaktiAI Brain

**Status:** Tagged release of Phase 3 (AI Brain core).
**Date:** 2026-08-07

Phase 3 delivers the foundation of **SaktiAI** — the AI-brain stack that turns
natural language into verifiable system actions, offline-first.

## Highlights

- **SaktiAI brain** (`ai/core/brain.py`) — orchestrator pipeline:
  `input → intent → context → planner → commands → actions → memory → report`.
- **Intent classifier** — recognizes `install`, `create`, `deploy`, `scan_network`,
  `organize`, `search`, `run`, `system`, and fallback `general`.
- **Planner** — rule-driven decomposition of each intent into ordered, verifiable
  steps (strategy pattern; LLM planner can slot in later).
- **Command translator** — strict-mode allow-list: unsafe commands are refused
  unless explicitly permitted.
- **Action pipeline** — executes steps with fail-fast / continue-on-error, dry-run
  mode, and post-run verification.
- **Memory** — persistent per-user store (history, recent commands, projects,
  preferences, pinned, workspaces) + in-process event bus.
- **Context** — live sensing: OS, CPU/RAM (via optional `psutil`), active window,
  current git project, internet probe (cached).
- **Voice baseline** — "Hey Sakti" wake word + voice engine (offline STT/TTS).
- **LLM + Providers** — OpenAI-compatible client (stdlib only) and a provider
  manager (`ollama` built-in, pluggable).
- **Plugin SDK** — base class + loader with per-intent handlers.
- **CLI** — `sakti chat/status/memory/providers/plugins/wake` and
  `scripts/sakti-ai`.
