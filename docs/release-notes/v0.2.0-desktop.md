# Release Notes — v0.2.0-desktop

**Date:** 2026-08-07
**Tag:** `v0.2.0-desktop`
**Series:** SaktiLinux AI — Desktop Experience

---

## Summary

Phase 2 delivers the complete desktop experience for SaktiLinux AI: a premium
glass shell built on KDE Plasma 6 / Wayland, a full Dynamic Workspace system
for switching between work modes, a brand-consistent theme pipeline, SVG icon
system, fonts, and login screen — all production-grade and tested.

## Highlights

- **Dynamic Workspace Mode System** — `sakti-modes` CLI switches between
  `default` / `developer` / `designer` / `cyber`. Each mode re-shapes the
  dock, launcher, widgets, shortcuts, accent color, and wallpaper.
  **Installed applications are never removed — only UI surfaces change.**
- **Floating Glass Shell** — dock, taskbar, control center, notification
  center, spotlight search, AI sidebar, workspaces.
- **Theme pipeline** — `themes/generate.py` renders KDE color schemes
  (`Sakti-{cyan,indigo,orchid}.colors`) from `branding/colors.json`.
- **Font Awesome style SVG icon system** + `SaktiIcons` theme.
- **Fonts** — Inter, JetBrains Mono, Geist.
- **SDDM glass login screen** + per-mode wallpapers.
- **6 Sakti plasmoids** (`org.kde.plasma.sakti.*`) — real Qt6 QML components.
